# NAVY STUDIO 회사 홈페이지

저장소 최상위의 HTML·CSS·JavaScript로 구성한 반응형 회사 소개 페이지입니다.
상단 메뉴, 회사 소개, 서비스 3개, 이메일·전화 문의 링크를 제공합니다.
모바일 메뉴는 버튼, 링크 선택, Escape 키, 화면 크기 변경에 대응합니다.

회사명 및 연락처는 샘플입니다. `index.html`에서 실제 정보로 변경하세요.

## 빌드

Node.js가 설치된 환경에서 `npm run build`를 실행하면 `dist/`에 배포 파일이 생성됩니다.
외부 패키지 설치는 필요하지 않습니다. `index.html`을 브라우저에서 직접 열어도 사용할 수 있습니다.

상단 버튼으로 다크모드와 화이트모드를 전환할 수 있습니다. 선택한 모드는 브라우저에 저장되며, 저장소 접근이 차단된 환경에서도 현재 페이지에서 전환할 수 있습니다.

## CEO AI 실무활용 요약

`ai-guide.html`은 업로드된 「CEO를 위한 AI 실무활용_완성본.pdf」(박경훈, 2026.10.14., 40쪽)를 바탕으로 개념, 업무 예시, 도구별 역할, 제작·배포 흐름, 회사 자료 반영과 결과 검토를 요약한 페이지입니다. 상단 메뉴와 첫 화면 안내에서 연결됩니다. 내용별 원자료 페이지를 표시하며 원본 PDF와 슬라이드 이미지는 배포하지 않습니다. 기존 테마 전환 및 모바일 메뉴를 공유합니다.
